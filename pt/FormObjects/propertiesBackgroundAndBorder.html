Fundo e margem

Cor de fundo alternado​

Permite definir uma cor de fundo diferente para linhas/colunas ímpares em uma caixa de listagem. Por padrão, Automático está selecionado para colunas de list box: a coluna usa a cor de fundo alternativa definida no nível da caixa de listagem.

Você também pode definir esta propriedade usando o comando OBJECT SET RGB COLORS.

Gramática JSON​

NomeTipo de dadosValores possíveis
alternateFillstringqualquer valor css; "transparent"; "automatic"; "automaticAlternate"

Objectos suportados​

List Box - Columna List Box

Comandos​

OBJECT GET RGB COLORS - OBJECT SET RGB COLORS

Background Color / Fill color​

Defines the background color / fill color of an object. It can be defined for some standard objects (fill JSON property) or "custom style" objects (borderFillColor JSON property).

nota

The Fill color property is named Background color with List Box, List Box Column and List Box Footer objects.

Standard objects​

No caso de uma coluna de list box, por padrão, Automático é selecionado: a coluna usa a cor de fundo definida no nível da caixa de listagem.

Gramática JSON​

NomeTipo de dadosValores possíveis
fillstringqualquer valor css; "transparent"; "automatic"

Objectos suportados​

Lista hierárquica - Entrada - List Box - Coluna List Box - Rodapé List Box - Oval - Rectângulo - Área de texto

Comandos​

LISTBOX Get row color - LISTBOX SET ROW COLOR - OBJECT GET RGB COLORS - OBJECT SET RGB COLORS

Custom button, custom check box, or custom radio button​

This property allows you to assign a fill color attribute to custom buttons, custom check boxes, or custom radio buttons. In addition, custom buttons must have the "custom" Border Line Style. In other contexts, the property is ignored.

Gramática JSON​

NomeTipo de dadosValores possíveis
borderFillColorstringqualquer valor css; "transparent"; "automatic"

Objectos suportados​

Custom Button (with "custom" Border Line Style) - Custom Check Box - Custom Radio Button

Comandos​

OBJECT GET RGB COLORS - OBJECT SET RGB COLORS

Background Color Expression​

List box de tipo coleção e seleção de entidades

Uma expressão ou uma variável (variáveis de matriz não podem ser usadas) para aplicar uma cor de fundo personalizada a cada linha da caixa de listagem. A expressão ou variável será avaliada para cada linha exibida e deve retornar um valor de cor RGB. For more information, refer to the description of the OBJECT SET RGB COLORS command.

Você também pode definir esta propriedade usando o comando LISTBOX SET PROPERTY com a constante lk background color expression.

Com os list box de tipo coleção ou seleção de entidades, esta propriedade também pode ser definida usando uma Meta Info Expression.

Gramática JSON​

NomeTipo de dadosValores possíveis
rowFillSourcestringUma expressão que retorna um valor de cor RGB

Objectos suportados​

List Box - Columna List Box

Comandos​

LISTBOX Get property - LISTBOX SET PROPERTY

Border Color​

Permite definir a cor da borda. O efeito desta propriedade varia ligeiramente dependendo do tipo de objeto ao qual ela é aplicada.

  • objetos com propriedades de texto: botões (todos os estilos exceto "custom", veja abaixo), listas hierárquicas, entradas, list boxes, indicadores de progresso, réguas e áreas de texto.
    Por padrão, a cor da borda desses objetos é definida automaticamente para a sua propriedade cor da fonte. Esta configuração padrão corresponde à opção Igual à fonte na Lista de Propriedades (a propriedade borderColor fica indefinida no JSON).
    Você pode separar essas duas propriedades definindo um valor de cor para a propriedade "Cor da borda" do objeto (disponível apenas quando a propriedade estilo de linha de borda é simples (solid na propriedade JSON) ou pontilhada).

  • objetos sem propriedades de texto: áreas 4D View Pro, áreas 4D Write Pro, grades de botões, botões de imagem, menus pop-up de imagem, áreas de plug-in, subformulários, spinners, splitters, steppers, áreas web.
    A propriedade cor da borda define a cor das bordas. O valor padrão da cor é "Automático", ou seja, a borda é exibida com a cor automática definida pelo seu sistema operacional.

  • botões com estilo customizado: custom buttons com "custom" Border Line Style, custom check boxes e custom radio buttons.
    Neste caso, a propriedade cor da borda define a cor de uma borda interna, que é um atributo do próprio objeto e não uma propriedade de decoração. Esta borda interna também pode ter uma largura (ela só é exibida se a largura > 0).

Gramática JSON​

NomeTipo de dadosValores possíveis
borderColorstringqualquer valor css; "transparent"; "automatic"

Objectos suportados​

Área 4D View Pro - Área 4D Write Pro - Botão - Grade de botões - Check Box ("custom" style) - Lista hierárquica - Entrada - List Box - Botão imagem - Menu pop-up com imagem - Área Plug-in - Indicador de progresso - Radio Button ("custom" style) - Regua - Área de texto - Spinner - Splitter - Stepper - Subformulário - Área web

Comandos​

OBJECT GET RGB COLORS - OBJECT SET RGB COLORS

Estilo de linha de borda​

Permite definir um estilo para o contorno do objeto. As seguintes opções estão disponíveis (nem todas as opções são possíveis dependendo do objeto):

EstiloObjetos (*)Descrição
NonetodosObjetos aparecem sem borda.
PlaintodosObjetos aparecem emoldurados com uma linha contínua de 1 pt. ("solid" valor json)
DottedtodosObjetos aparecem emoldurados com uma linha pontilhada de 1 pt.
RaisedtodosObjetos aparecem emoldurados com um efeito 3D.
SunkentodosObjetos aparecem emoldurados com um efeito 3D rebaixado.
DoubletodosObjetos aparecem emoldurados com uma linha dupla, ou seja, duas linhas contínuas de 1 pt separadas por um pixel.
Systemtodos exceto botões e áreas de textoObjetos aparecem com uma linha de borda baseada nas especificações gráficas do sistema operacional.
System roundedentradasNo macOS, objetos aparecem com o efeito nativo de borda "Liquid Glass" do sistema (para informações sobre Liquid Glass, veja este post do blog 4D). Inclui borda interna definida pelo sistema, raio de canto, cor de borda cinza e padding interno. Note que a aparência "Liquid Glass" não é usada em um objeto de entrada multilinha se a propriedade de barras de rolagem estiver ativada ("System" é usada neste caso).
No Windows, este estilo é semelhante ao "System" em tempo de execução.
Customcustom buttonsHabilita o design de borda interna, que inclui um conjunto de propriedades extras: Cor de preenchimento, Cor da borda, Largura da borda e Raio do canto.

(*) "todos" significa "todos os objetos suportados" listados abaixo.

Border Width​

Allows defining the width of the inner border for:

  • custom buttons with the "custom" Border Line Style,
  • custom check boxes,
  • custom radio buttons.

In other contexts, the property is ignored.

The value is expressed in pixels.

Gramática JSON​

NomeTipo de dadosValores possíveis
borderWidthnumberInteger value (pixels). Minimum value = 0

Objectos suportados​

Botão ("custom" style) (with "custom" Border Line Style) - Check Box ("custom style") - Radio Button ("custom" style)

Retângulo​

História
ReleaseMudanças
21 R5Support for custom-styled buttons, radio buttons and check boxes
19 R7Support for inputs and text areas

Define o arredondamento do canto (em pixels) do objeto. Por padrão, o valor do raio é 0 pixels. Você pode alterar essa propriedade para desenhar objetos arredondados com formas personalizadas:

O valor mínimo é 0; nesse caso, um retângulo de objeto padrão não arredondado é desenhado. O valor máximo depende do tamanho do retângulo (ele não pode exceder metade do tamanho do retângulo menor) sendo calculado dinamicamente.

In text areas and inputs:

  • the corner radius property is only available with "none", "solid", or "dotted" border line styles,
  • the corner roundness is drawn outside the area of the object (the object appears larger in the form but its width and height are not extended).

In custom buttons (with a "custom" Border Line Style), custom check boxes and custom radio buttons, the corner radius is drawn inside the area of the object.

Cor da linha​

Designa a cor das linhas do objeto. A cor pode ser especificada por:

  • um nome de cor - como "red"
  • um valor HEX - como "#ff0000"
  • um valor RGB - como "rgb(255,0,0)"

Você também pode definir esta propriedade usando o comando OBJECT SET RGB COLORS.

Gramática JSON​

NomeTipo de dadosValores possíveis
strokestringum valor css, "transparent", "automatic"
nota

Essa propriedade também está disponível para objetos com propriedades de texto, neste caso ela designa tanto a Cor da fonte quanto as linhas do objeto, exceto se você usou a propriedade Cor da borda.

Row Background Color Array​

List boxes de tipo array

O nome de um array para aplicar uma cor de fundo personalizada para cada linha ou coluna da list box.

Deve ser introduzido o nome de um array Longint. Cada elemento deste array corresponde a uma linha do list box (se aplicada o list box) ou a uma célula da coluna (se aplicada a uma coluna), pelo que o array deve ter o mesmo tamanho que o array associado à coluna. Você pode usar as constantes descritas no comando OBJECT SET RGB COLORS. Se você quiser que a célula herde a cor de fundo definida em um nível superior, passe o valor -255 para o elemento correspondente do array.

Por exemplo, dada uma caixa de listagem em que as linhas têm uma cor alternada de cinza/cinza claro, definida nas propriedades da caixa de listagem. Um array de cor de fundo também foi definida para a caixa de listagem, a fim de mudar a cor das linhas em que pelo menos um valor é negativo para laranja claro:

 <>_BgndColors{$i}:=0x00FFD0B0 // laranja
 <>_BgndColors{$i}:=-255 // valor por padrão

De seguida, deve colorir as células com valores negativos a laranja-escuro. Para fazer isso, você definiu um array de cor de fundo para cada coluna, por exemplo, <>_BgndColor_1, <>_BgndColor_2 e <>_BgndColor_3. Os valores dessas arrays têm prioridade sobre os valores definidos nas propriedades da caixa de listagem, bem como sobre os valores do array geral de cores de fundo:

 <>_BgndColorsCol_3{2}:=0x00FF8000 // laranja escura
 <>_BgndColorsCol_2{5}:=0x00FF8000
 <>_BgndColorsCol_1{9}:=0x00FF8000
 <>_BgndColorsCol_1{16}:=0x00FF8000

Você pode obter o mesmo resultado usando os comandos LISTBOX SET ROW FONT STYLE e LISTBOX SET ROW COLOR. Eles têm a vantagem de permitir que você não precise predefinir matrizes de estilo/cor para as colunas: em vez disso, elas são criadas dinamicamente pelos comandos.

Gramática JSON​

NomeTipo de dadosValores possíveis
rowFillSourcestringO nome de um array longint.
