## Description 

<!--REF #_command_.STOP MONITORING ACTIVITY.Summary-->The **STOP MONITORING ACTIVITY** command stops tracking activity started with the [START MONITORING ACTIVITY](../commands/start-monitoring-activity) command.<!-- END REF--> After the execution of this command, any activity record in memory is emptied.

This command can be called and executed on 4D remote, 4D Server, and 4D standalone applications.
