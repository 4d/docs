## Description 

<!--REF #_command_.End SQL.Summary-->**End SQL** is a keyword indicating the end of a sequence of SQL commands in the Method editor.<!-- END REF--> 

A sequence of SQL statements must be enclosed with the [Begin SQL](../commands/begin-sql) and **End SQL** keywords. For more information, refer to the description of the [Begin SQL](../commands/begin-sql) keyword.
