## Description 

<!--REF #_command_.WA REFRESH CURRENT URL.Summary-->La commande **WA REFRESH CURRENT URL** provoque le rechargement de l’URL courant affiché dans la zone Web désignée par les paramètres *\** et *objet*.<!-- END REF-->
