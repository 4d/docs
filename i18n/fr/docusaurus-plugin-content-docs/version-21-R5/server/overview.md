Lorsque 4D Server est lancé avec son interface sous Windows ou macOS, vous pouvez [créer ou ouvrir des projets](../Desktop/clientServer.md#opening-a-remote-project) et effectuer des opérations d'administration via une barre de menus et une [fenêtre d'administration graphique](../ServerWindow/overview.md).

> La fenêtre d'administration de 4D Server est accessible depuis un 4D distant. Pour plus d'informations sur ce point, veuillez vous référer à la page [Administration à partir de machines distantes](../ServerWindow/remote-admin.md) .
