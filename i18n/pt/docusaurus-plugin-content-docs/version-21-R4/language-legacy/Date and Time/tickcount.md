## Descrição 

<!--REF #_command_.Tickcount.Summary-->Tickcount retorna o número de tics (1 tic = 1 / 60 avos de um segundo) passados desde que se iniciou a máquina.<!-- END REF-->Tickcount retorna um valor de tipo Inteiro longo.
