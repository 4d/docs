## Descrição 

<!--REF #_command_.STOP MONITORING ACTIVITY.Summary-->O comando **STOP MONITORING ACTIVITY** para o rastreamento da atividade iniciado com o comando [START MONITORING ACTIVITY](../commands/start-monitoring-activity).<!-- END REF--> Depois da execução desse comando, qualquer atividade registrada na memória é esvaziada.

Este comando pode ser chamado e executado em 4D remote, 4D Server e aplicações 4D standalone.
