## 説明 

<!--REF #_command_.Get cache size.Summary-->**Get cache size**コマンドは、カレントデータベースのキャッシュサイズをバイト単位で返します。<!-- END REF-->このコマンドはローカルモード (4D Server および 4D) でのみ正しい情報を返します。リモートモードの4Dでの使用は想定されていないことに注意してください。
