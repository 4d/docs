## Descripción

Este evento se activa cuando se han validado los datos introducidos en el registro, por ejemplo, tras una [acción estándar](FormObjects/properties_Action.md#standard-action) `accept`.

### Subformulario

El evento `On Validate` se activa cuando se valida la entrada de datos en el subformulario.
