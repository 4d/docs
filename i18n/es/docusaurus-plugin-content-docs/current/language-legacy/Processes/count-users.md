## Descripción 

<!--REF #_command_.Count users.Summary-->El comando **Count users** devuelve el número de usuarios conectados al servidor.<!-- END REF-->  
  
Cuando se ejecuta en una aplicación 4D monousuario, **Count users** devuelve 1.
