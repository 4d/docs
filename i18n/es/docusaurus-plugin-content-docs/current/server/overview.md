title: 4D Server

Al iniciar 4D Server con interfaz en Windows o macOS, puede [crear o abrir proyectos](../Desktop/clientServer.md#opening-a-remote-project) y realizar acciones de administración desde una barra de menús y una [ventana gráfica de administración](../ServerWindow/overview.md).

> Se puede acceder a la ventana de administración de 4D Server desde un 4D remoto. Para más información sobre este punto, consulte la página [Administración desde máquinas remotas](../ServerWindow/remote-admin.md).
